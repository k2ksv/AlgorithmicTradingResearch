# NIFTY 50 Trend-Based Risk Overlay

## Overview
This project studies the effectiveness of simple moving-average trend signals
when used as a **risk management overlay** on a Buy & Hold equity index strategy.

The objective is NOT to outperform the market, but to:
- Reduce maximum drawdowns
- Improve risk-adjusted returns
- Provide a disciplined exposure framework

## Methodology
- Asset: NIFTY 50 Index
- Indicators: 50-day and 200-day moving averages
- Exposure levels: 0%, 50%, 100%
- Overlay applied to Buy & Hold returns
- Metrics: CAGR, Sharpe Ratio, Max Drawdown

## Key Findings
- Standalone MA strategies fail to generate alpha on indices
- Trend signals are effective as **risk filters**
- Overlay significantly reduces drawdown
- Sharpe ratio improves versus standalone timing strategies

## Conclusion
Trend-following rules should be used for **risk control**, not return prediction.
This project demonstrates a practical and defensible use-case for such signals.
